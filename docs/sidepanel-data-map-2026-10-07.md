# 종합상황 사이드패널 — 어떤 데이터가 실제이고 어디가 임의(샘플)인가 (2026-10-07)

Figma "1단계 · 종합상황 좌·우 사이드패널"(L1~L4, R1~R8, R00)을 `/dashboard` 종합상황에 반영했다. 레이아웃은 디자인 그대로이고,
데이터는 **실제로 받을 수 있는 것은 실데이터**, **없는 것은 임의 데이터(샘플)** 로 채웠다. 샘플에는 화면에 항상 **"샘플"** 표식이 붙는다.
샘플 값은 전부 **`src/data/sidePanelSamples.ts` 한 파일**에 있다(화면 컴포넌트에는 숫자를 직접 쓰지 않는다) — 나중에 입력 패널이나 실연동으로 바꿀 자리다.

구현 위치: `src/components/sidepanel/*`(패널), `src/styles/sidepanel.css`(스타일), `src/data/useSidePanelEvents.ts`(좌측 사건 목록 수집).
GIS 상황의 우측 패널은 결정(2026-10-07)대로 L1~L4를 그대로 재사용한다.

## 환경별 표시 (2026-10-07 사용자 결정)
- **스테이징**(`npm run build:staging` = vite `--mode staging`): 좌측 L1·L2·L4는 **항상 샘플**(레이아웃 확인용 임의 데이터, "샘플" 표식 + "스테이징 환경입니다" 안내). 입력 패널 값은 그대로 우선한다.
- **프로토타입·로컬**: 현재 데이터가 있으면 그 값(0건이면 0건). 샘플은 데이터를 못 받았을 때만.
- 판단은 `useSidePanelEvents.ts`의 `IS_STAGING`(`import.meta.env.MODE === "staging"`). 동네예보·대피소 스냅샷처럼 항상 실제 값인 자리는 환경과 상관없이 실데이터.

## 표시 규칙 (2026-10-07 사용자 결정)
- **데이터가 있으면(값이 0이거나 비어 있어도) 그 값 그대로** 보여준다. 예: 기상청 특보 API가 정상 응답했는데 0건이면 "0건 · 발표된 특보 없음"이지 샘플이 아니다.
- **데이터가 없을 때만 샘플**을 보여주고 **"샘플" 표식을 반드시** 붙인다. 입력 패널로 넣은 값에는 "입력값" 표식이 붙는다.
- 영역마다 따로 판단한다(한 탭 안에서도 입력한 영역은 입력값, 안 한 영역은 샘플). 탭 전체가 샘플이면 제목 옆에 "샘플" 표식을 한 번만 단다.
- 우측 패널은 좌측 패널과 같이 **제목 줄 → 탭 줄** 순서다(방재메신저·안전뉴스만 디자인대로 제목이 "예정 기능").

## 입력 패널 — `/panel-input` (헤더 메뉴 "패널 입력")
센서(센서정보·센서 추이)와 대응 단계(대응현황)의 값을 직접 넣는다. **이 브라우저의 localStorage(`jeju-ax-panel-input`)에만 저장**되고 입력하면 바로 저장된다.
영역마다 "직접 입력 시작"(샘플 값이 입력칸에 채워진 채 시작) → 고치면 패널에 그대로 반영, "샘플로 되돌리기"로 그 영역만 샘플로 복귀, "모두 샘플로 되돌리기"로 전부 복귀.
저장소·타입은 `src/data/panelInput.ts`(서비스 목록 `SERVICES`에 한 줄 더하면 입력 화면·타일이 같이 늘어남), 화면은 `src/pages/PanelInputPage.tsx`.

| 영역 | 패널 | 입력 항목 |
|---|---|---|
| sensorSummary | R2 센서 수집 상태 | 정상·지연·오류·미연계 개수(전체는 합) |
| serviceSensors | R2 서비스 타일 | 서비스별 센서 수, 최고 위험등급(미입력 = 정보 없음) |
| sensorAlerts | R2 확인 필요 센서 | 센서 이름·서비스·사유·표시값·등급·배지 문구 |
| trends | R3 위험 임박 순위·대표 추이 | 서비스·지표 이름·단위·관측값(쉼표)·예측값·기준값/이름·위험 방향·등급 — 순위·추세 화살표·눈금 위치는 계산 |
| stages | R4 서비스 타일·조치 진행 | 서비스별 단계·단계 옆 숫자(선택)·조치 완료/진행/대기 — 합계·막대는 계산 |
| actions | R4 지금 해야 할 조치 | 서비스·내용·상태 |
| responseExtra | R4 기관 연결·현장 대응팀 | 기관 수·문제 문구·대응팀 수·상태 문구 |

## 알아둘 점
- "샘플"은 실제 상황이 아니다. 디자인 레이아웃이 어떻게 채워지는지 보려는 값이다.
- R2·R3·R4의 센서·대응 단계는 앱에 실제 데이터 원천이 아직 없어 입력 패널로 채운다. R7 자산현황은 아직 입력 패널이 없다(샘플).
- L1~L4는 기상청 특보·태풍 응답을 하나라도 받으면 샘플을 쓰지 않는다.
